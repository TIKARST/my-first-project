# \# Image Batch Converter

# 

# A simple Python script for converting images in bulk from PNG to JPG and other formats.

# 

# \## Features

# \- Converts images in a folder recursively

# \- Supports PNG, JPG, JPEG, BMP, WEBP

# \- Saves converted files to an output directory

# \- Keeps the folder structure

# \- Allows quality control for JPG and WEBP outputs

# 

# \## Requirements

# \- Python 3.9+

# \- Pillow

#
